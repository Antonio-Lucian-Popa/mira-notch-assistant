Under the hood

Built for speed & privacy.

A shared Rust core drives everything. The OS just draws it — natively.

🦀 Rust core & daemon

All the logic — state, lyrics sync, storage — lives in a tiny, well-tested Rust core. A daemon exposes it over D-Bus.

🖥️ Native UI

On GNOME it’s a Shell extension (GJS). Windows preview uses a native Win32 window. No browser engine shipped.

🎨 One design token file

Sizes, colors, motion and pages come from a single JSON, to keep the native hosts visually related as Windows support grows.

🔌 Event-driven

Media discovery reacts to events from every player. Countdown timers update while needed; animation work stops when a view is inactive.

🔒 Local-first

No accounts, no telemetry. The sole network request is to LRCLIB for lyrics.

🖐️ Multi-monitor aware

Lives only on your primary monitor and recentres itself when you plug or unplug a screen.

Ubuntu / GNOME

Available now

GNOME 46–48 on Wayland or Xorg. Install the .deb from GitHub Releases, or build from source.

# Download the .deb from GitHub Releases
sudo apt install ./mira_*_amd64.deb

systemctl --user enable --now mira-daemon
# Log out and back in, then enable:
gnome-extensions enable mira@novabytecode.ro

Good to know

FAQ

Does it phone home?

No. There’s no account and no telemetry. The only network request is to LRCLIB for lyrics. Searches include the song metadata, or the title and artist you explicitly enter.

Will it slow my machine down?

No webview, no Electron — just a small Rust daemon and a native UI. It targets ~0% idle CPU and under 40 MB of RAM, and only redraws while something animates.

Which Linux versions are supported?

GNOME Shell 46, 47 and 48, on Wayland or Xorg. Other desktops aren’t supported yet.

Can I add files to the shelf by drag & drop?

On Wayland the system doesn’t allow dropping files onto shell chrome, so Mira gives you two reliable ways instead: copy a file and press Ctrl+V on the Shelf page, or run mira-add <file> from your file manager.

What works on Windows?

The native preview includes cursor-following eyes, media keys, Pomodoro, water and reminders. The installer supports per-user installation and optional sign-in startup. Track metadata, lyrics, daily-rhythm settings and other GNOME features are still pending.

Why is my Incognito song title hidden?

Chromium-based browsers may deliberately replace it with “A site is playing media”. Mira cannot reconstruct information the browser withholds. In the GNOME Lyrics page, enter a title and artist to look up lyrics explicitly; availability depends on LRCLIB.

Is it really free?

Yes — MIT licensed, forever. Contributions welcome.
