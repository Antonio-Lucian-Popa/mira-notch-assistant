Say hi to Mira

Eyes with a personality.

The resting face isn’t a clock — it’s a pair of eyes that actually feel alive. They track your cursor, blink at random, and have a whole library of moods you can pin or shuffle.

Under the hood

Built for speed & privacy.

A shared Rust core drives everything. The OS just draws it — natively.

🦀 Rust core & daemon

All the logic — state, lyrics sync, storage — lives in a tiny, well-tested Rust core. A daemon exposes it over D-Bus.

🖥️ Native UI

On GNOME it’s a Shell extension (GJS). On Windows it’ll be a native window. No browser engine shipped.

🎨 One design token file

Sizes, colors, motion and pages come from a single JSON, so both OSes look pixel-identical.

🔌 Event-driven

Mira subscribes to OS events instead of polling, and only redraws while an animation runs.

🔒 Local-first

No accounts, no telemetry. The sole network request is to LRCLIB for lyrics — and you can turn it off.

🖐️ Multi-monitor aware

Lives only on your primary monitor and recentres itself when you plug or unplug a screen.

Ubuntu / GNOME

Available now

GNOME 46–48 on Wayland or Xorg. Build from source today; a .deb is on the way.

# 1 — build the daemon (needs Rust)
cargo build --release -p mira-daemon

# 2 — install the GNOME extension
./gnome-extension/build.sh install

# 3 — log out / in, then enable
gnome-extensions enable mira@novabytecode.ro

Good to know

FAQ

Does it phone home?

No. There’s no account and no telemetry. The only network request is to LRCLIB for lyrics, and it’s the single networked code path in the project.

Will it slow my machine down?

No webview, no Electron — just a small Rust daemon and a native UI. It targets ~0% idle CPU and under 40 MB of RAM, and only redraws while something animates.

Which Linux versions are supported?

GNOME Shell 46, 47 and 48, on Wayland or Xorg. Other desktops aren’t supported yet.

Can I add files to the shelf by drag & drop?

On Wayland the system doesn’t allow dropping files onto shell chrome, so Mira gives you two reliable ways instead: copy a file and press Ctrl+V on the Shelf page, or run mira-add <file> from your file manager.

When is Windows coming?

It’s the next milestone. The shared core and design already exist — the Windows host wires them to native APIs. Watch the repo to be notified.

Is it really free?

Yes — MIT licensed, forever. Contributions welcome.
